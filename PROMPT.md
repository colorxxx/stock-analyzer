Build a Next.js stock analysis web app with these features:

1. Homepage with search bar to enter a stock ticker like AAPL, TSLA, CLS
2. Stock page with interactive candlestick chart using lightweight-charts from TradingView showing price history
3. Timeline analysis where user can select a date range on the chart and get AI analysis for that period including price movement analysis, earnings/fundamentals overlay showing earnings dates on chart, and technical indicators like RSI, MACD, moving averages
4. Chat interface as an interactive chat panel on the right side where user can ask questions about the stock, powered by an LLM API endpoint
5. Use yahoo-finance2 npm package for stock data
6. Dark theme, clean modern UI with Tailwind CSS
7. Deploy-ready for Vercel

Tech stack: Next.js 14 App Router, TypeScript, Tailwind CSS, lightweight-charts, yahoo-finance2

Start with a working MVP with chart, basic data display, and chat UI. Make it functional.
